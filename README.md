# Ancestors Aura

A premium African heritage storefront and storytelling experience, built with React, TypeScript and Vite.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Current implementation
- Responsive editorial storefront with animated hero imagery and hover depth effects.
- Collection filters, product search, add-to-bag interaction and TZS display.
- Story, heritage, about and newsletter preview sections.
- Mobile navigation and accessible control labels.

## Important integration status
This is the frontend starter. Product cards currently use demonstration content and images. The bag is a local preview interaction only. Newsletter submission displays a preview notice. No real payment, checkout, customer account, inventory, order, or shipping data is connected yet.

## Shopify production integration
Use Shopify as the commerce source of truth. Connect products, collections, availability, cart, customer accounts, discounts, shipping and checkout through Shopify's supported storefront APIs or a Shopify theme implementation. Never simulate successful payment or order creation. Keep credentials in environment variables and never commit Admin API secrets.

The connected store is configured separately. Do not publish to the live theme until the owner reviews and approves the preview.

## Design direction
Warm charcoal, parchment, muted brass and earthy photography. Display typography uses Playfair Display and interface typography uses DM Sans.
